## Featured project

### Security Log Analysis and Alert Dashboard

A Python and Streamlit lab that analyses synthetic authentication logs.

- Detects repeated authentication failures.
- Identifies successful logins following repeated failures.
- Flags one IP targeting multiple accounts.
- Displays login metrics, charts, and authentication events.
- Includes validation for suspicious and spaced-out activity.
